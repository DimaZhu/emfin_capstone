# One argument for a 30-page paper

**Question:** how do scenario-tail and liquidity assumptions change funding-risk
allocations for an illiquid family balance sheet?

1. Problem and client evidence: obligations, holdings, illiquidity and what is still missing.
2. One common scenario interface and one proposed liability-aware allocation model.
3. Fair comparison: 1/N, common shrunk MV and the proposed model, on identical inputs.
4. One stress panel: funding ratio and tail/liquidity assumptions, with uncertainty.
5. Validation: independent Monte Carlo, chronological development protocol, short-history
   limits and an untouched final window. Distinguish code validation from client evidence.
6. Client implications, limits and what additional data would change the decision.

Put BL, SeqEP variants, Sobol/antithetic experiments, MPEP/CML/DRO variants,
solver details and extra sensitivity grids in appendices. Keep methods that do
not change the central conclusion out of the main text. Do not frame synthetic
or placeholder exhibits as findings about the real client. A sleeve can demonstrate
plumbing before its calibration is empirical; those are different achievements.
